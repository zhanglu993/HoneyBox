## ECG path (Polar Measurement Data / PMD)

ECG is **not** on the standard Heart Rate service. Raw ECG streams from Polar’s proprietary **PMD** service:

| Role | UUID | Notes |
| --- | --- | --- |
| PMD Service | `fb005c80-02e7-f387-1cad-8acd2d8df0c8` | Polar Measurement Data |
| PMD Control Point | `fb005c81-02e7-f387-1cad-8acd2d8df0c8` | CCCD present — start/stop/request settings (write + indicate) |
| PMD Data | `fb005c82-02e7-f387-1cad-8acd2d8df0c8` | CCCD present — notify stream (ECG / ACC / … frames) |

Typical flow: enable notify on Data + indicate/notify on Control Point → write start-ECG request to Control Point → parse ECG frames on Data notifications.

Heart Rate (`0000180d…` / `00002a37…`) only gives BPM (+ optional RR), not ECG samples.
